📌 扩展概述

QOT语言原生方法可能无法满足您的全部使用需求，如需扩展功能，您可通过导入外部库来便捷地使用更多能力！在开始扩展前，您需要提前准备好该库对应的DLL文件，以及FUNC格式的配置文件。

📄 FUNC配置文件 用于存储库的核心必要信息，例如导出的函数名称、各函数的参数类型及返回类型。完成FUNC配置文件编写后，需使用我们提供的签名工具进行签名，再将签名后的配置文件与库的DLL文件一同放置到指定的库文件夹中。 ✓ 安全签名校验机制

✍️ FUNC配置文件编写规范

导出函数名|参数类型|返回类型
💡 格式说明： 参数类型需用英文逗号（,）分隔多个参数；每个导出函数需单独占一行。签名工具会将配置文件转换为受信任的库描述。

🔁 参数类型映射表

下表展示了原生C/C++数据类型与QOT语言内部类型的对应关系，确保跨语言调用时参数准确传递。

⚡ 变参函数（可变参数）
若函数参数数量不固定，请在 FUNC 配置文件中将参数类型写为 ...
例如：printf|...|int 或 call_address|...|dword
调用时可按需传入任意数量的参数，QOT 会自动处理参数传递。

⚙️ 注意事项：
• str 类型对应 UTF-8 编码的字符串，QOT 默认使用 UTF-8。
• wca 类型用于 Windows W 版本 API（如 MessageBoxW），需要宽字符串。
• ptr / void / hwnd 等句柄类型在 QOT 中显示为数字，可直接用于计算或传递。
• 变参函数（参数类型写为 ...）可以接收任意数量的参数，常用于 call_address、call_func 等通用调用函数。

📚 快速上手 · 示例示范

🔧 编写 FUNC 配置文件范例：
假设您的动态库 math_ext.dll 中有两个导出函数，签名如下：
  • int add(int a, int b) → 参数类型: int,int 返回类型: int
  • double div(double a, double b) → 参数类型: double,double 返回类型: double
则 FUNC 配置文件内容应为：
add|int,int|int div|double,double|double
完成签名后，与 math_ext.dll 一同放入库文件夹，即可在 QOT 中调用。

🛡️ 签名与部署要点

📁 库文件夹默认路径：/package/库/ 🔐 未签名的FUNC配置文件将被拒绝加载
🧩 目录结构示例：
/package/库/
  ├── mylib.dll  （动态链接库）
  └── mylib.func  （签名后的配置文件）
请确保库文件名与配置文件名前缀一致，便于运行时索引。

⚙️ 介绍

QTC 文件 配套的 DLL 设计。当动态库使用 QOT 提供的 platform_ept.h 编译后，DLL 内部会自带导出函数表
不需要编写 .func 配置文件，也不需要签名，复制 DLL 即可使用。 仅限 QTC 工程产物

📈 相比方案一的优势

✅ 零配置文件 ✅ 无需签名流程 ✅ 加载速度更快 ✅ 单个 DLL 分发 ✅ 调用开销更低
省去磁盘读取和文本解析，DLL 直接向调用方提供函数列表，适合正式发布及对性能有要求的场景。

🎯 适用条件

• DLL 必须使用 QOT 标准插件头文件（platform_ept.h）编译生成。
• 通常配合 QTC 编译流程产出，编译后 DLL 具备自描述能力。
• 适合不想暴露函数签名文件、追求简洁部署的开发者。

🖥️ 平台库代码模板

使用以下模板编译生成的 DLL
#include "platform_ept.h" static PluginValue Add_wrapper(const PluginValue* args, int n) { if (n < 2) return PluginValue(0); double a = args[0].num_val; double b = args[1].num_val; return PluginValue(a + b); } PLUGIN_BEGIN g_exporter->add("add", Add_wrapper); PLUGIN_END
⚡ 包含 platform_ept.h 后，用 PLUGIN_BEGIN/PLUGIN_END 注册函数即可。编译完成后，DLL 可直接放入 package 目录。

📌 补充说明

  • 兼容性： 方案二与方案一可共存。如果 DLL 不支持自描述接口，系统会自动回退读取 .func 文件，不影响已有项目。
  • 编译要求： 需要包含 platform_ept.h（头文件已提供），并链接对应运行时。
  • QTC 配套： 该模式是 QTC 编译产物的标准特性
