本页覆盖 QOT 全部内置函数，共 — 个名字（含兼容别名）。 QOT 现在有两个活跃运行时：解释器（qguoat run x.qot）与 原生可执行文件（qguoat aot x.qot -o x.exe）。两者的内置函数面 并不相同，卡片右下角逐条标注两端的可用性。

标「缺席」的函数不能出现在 AOT 产物里（编译期就会报「该内置在原生后端缺席」）； 标「旧 VM」的条目属于已冻结的字节码 VM，不再是可用面。函数语义、参数与返回值的权威定义在仓库的 builtins.toml，本表由 _gen_builtin_docs.py 从该清单生成； 标准库（std/）函数不在本表，见 标准库参考。
