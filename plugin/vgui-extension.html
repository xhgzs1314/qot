概述

Vgui 是 QOT 内置的现代化图形界面库，基于 DirectComposition + Direct2D + DirectWrite 硬件加速渲染（D3D11 合成交换链，DWM 直接合成；老系统自动回退经典 HwndRenderTarget 路径，诊断开关 QOT_GUI_NO_DCOMP=1 可强制回退），提供以下核心能力：

  • 20+ 内置控件：Button、Card、CheckBox、Toggle、TextBox、Slider、ProgressBar、ComboBox、ListBox、TabControl、Spinner、Canvas（自由绘制）、Image（WIC 解码）等
  • 事件双通道：回调注册（qg_bind 函数指针 + userdata，任意宿主语言可用）与队列轮询（v1 兼容）并存；回调在消息泵空闲点延迟一跳派发，回调线程 = 消息循环线程，回调内可直接调用任何 qg_* 接口
  • 绘制原语（Canvas 回调内自由组合）：矩形/圆角矩形/椭圆的填充与描边、线、文本、渐变、裁剪（可嵌套）、平移/旋转/缩放变换（可嵌套）、层模糊、图片；另有窗口级原语：透明、系统 backdrop、圆角、无边框
  • 帧原语：qg_on_frame + qg_request_frame（rAF 模型，不请求即停帧零空转）+ qg_easing 12 种缓动纯函数 + qg_animate 属性动画糖
  • 完整动画系统：支持 12 种缓动曲线（Linear、Quad、Cubic、Sine、Elastic、Bounce）
  • 主题系统：深色/浅色主题 + 自定义配色方案
  • 布局辅助：Anchor、Dock、Flex、Grid 布局支持
  • IME 输入法支持：完整的输入法组合窗口处理

杂项

  • 布局系统：vg_layout_begin/add/props/end——vbox/hbox/grid，margin/padding/spacing/fill/align/weight；vg_layout_add 即快照自然尺寸，resize 自动重排；与绝对坐标共存；layout_theme 的 Anchor 并入 Absolute 模式重排（不留两套）
  • 滚动容器 + 虚拟化列表：vg_create_scrollpane / vg_scroll_attach（内容坐标托管子组件）+ vg_create_vlist / vg_list_on_data（万行级只画可视行，vg_list_draw_count 自证）；滚轮/拖拽/编程滚动统一发 kind=16
  • 模态对话框 + 菜单：vg_show_dialog(win, parent)（阻塞至关闭返回结果码，父窗冻结，嵌套天然支持）+ vg_create_menu / vg_menu_popup + vg_toast 自绘轻提示
  • 文本富能力：vg_draw_text_ex（粗体/对齐/自动换行/省略号）+ vg_draw_measure_text_ex（换行后实测宽高，布局量行高用；回调外可调）
  • 系统集成：vg_clipboard_set/get（CF_UNICODETEXT）、vg_window_accept_files + vg_take_drop_file（kind=51）、vg_taskbar_progress/state（ITaskbarList3）
  • 帧驱动修正：动画/帧请求活跃期自动 timeBeginPeriod(1) + 8ms 心跳（winmm 动态解析，不进导入表）——高频动画从 34fps 提到 vsync 锁定的 ≈60fps；空闲自动还原（测量结论：瓶颈在节拍不在重绘，visual 分层暂缓）

样式通理—— 原语哲学贯彻到组件层

  • 样式叠加层：UIComponent 挂 CompStyle（背景/渐变/边框/圆角/内边距/文字），字段 isSet 才生效——零定制时行为与旧版逐位一致（向后兼容铁律）。状态色（悬停/按下/禁用/焦点）独立叠加，命中优先级 禁用 > 按下 > 焦点 > 悬停
  • 绘制接管（owner-draw）：vg_on_paint(id, fn) 注册后组件默认绘制整体让位，每帧 fn(w, h, state)——回调里 vg_draw_* 原语自由作画（坐标 = 组件本地原点，与 Canvas 同一执行上下文）；组件退化为「交互语义 + 自由画布」：Button 接管后可以画成环形进度、星级评分、任何东西，点击/拖拽语义照旧。容器（Card/ScrollPane/VirtualList）不接管（子组件绘制语义保留）
  • 菜单自绘化：v3 的 Win32 HMENU 换成数据（MenuDef）+ 自绘无边框 popup 窗口——样式四件套（背景/悬停高亮/文字/描边）可定制；hover 高亮、键盘 ↑↓/Enter/ESC、失焦取消、屏幕边缘防越界；同步语义与 kind=50 不变
  • 部件样式：vg_toast_style（Toast 背景文字描边圆角）、vg_scroll_style（滚动条轨道/把手/宽度）
  • API 面：新增 17 个 vg_*（全部双引擎四处登记）；验收 testing/gui/style_demo.qot（29 断言双跑 + 回退路径）+ 消息注入探针（菜单点选/键盘导航）
设计哲学（v2 定纲）： 框架只提供原语，不封装成品效果——毛玻璃 = 透明窗口 + 半透明背景 + backdrop 原语自由组合；流畅动画 = 帧原语 + 缓动纯函数自己写；精致视觉 = 绘制原语自由作画。上限在开发者手里，不在框架里。
扩展目标： 你可以为 Vgui 添加新控件、扩展绘制原语、扩展动画缓动函数、创建自定义主题、定制布局行为。

  • FillEllipse / DrawEllipse - 椭圆
  • DrawLine - 线段

  • DrawText / MeasureText - 文本渲染与测量

添加新绘制原语（例如绘制三角形）

// 在 renderer.h 中添加声明
void FillTriangle(const Triangle& triangle, const Color& color);

// 在 renderer.cpp 中实现
void Renderer::FillTriangle(const Triangle& triangle, const Color& color) {
    if (!m_renderTarget) return;
    
    ID2D1SolidColorBrush* brush = GetBrush(color);
    if (!brush) return;
    
    // 使用 Direct2D 的 FillGeometry 绘制三角形
    ID2D1PathGeometry* pathGeometry = nullptr;
    ID2D1GeometrySink* sink = nullptr;
    
    m_d2dFactory->CreatePathGeometry(&pathGeometry);
    pathGeometry->Open(&sink);
    
    sink->BeginFigure(
        D2D1::Point2F(triangle.p1.x, triangle.p1.y),
        D2D1_FIGURE_BEGIN_FILLED);
    sink->AddLine(D2D1::Point2F(triangle.p2.x, triangle.p2.y));
    sink->AddLine(D2D1::Point2F(triangle.p3.x, triangle.p3.y));
    sink->EndFigure(D2D1_FIGURE_END_CLOSED);
    sink->Close();
    
    m_renderTarget->FillGeometry(pathGeometry, brush);
    
    SafeRelease(&sink);
    SafeRelease(&pathGeometry);
}

// 实现缓动函数
inline float EasingBackOut(float t) {
    const float c1 = 1.70158f;
    const float c3 = c1 + 1;
    return 1 + c3 * powf(t - 1, 3) + c1 * powf(t - 1, 2);
}

// 在 Animation::EvaluateEasing 中添加 case
case EasingType::BackOut:
    return EasingBackOut(t);

创建新控件

所有控件继承自 UIComponent 基类：

class UIComponent {
public:
    virtual ~UIComponent() = default;
    virtual void Draw(Renderer* renderer) = 0;
    virtual void Update(float deltaTime) {}
    virtual bool HandleMouseMove(const Point& mousePos) { return false; }
    virtual bool HandleMouseDown(const Point& mousePos, int button) { return false; }
    virtual bool HandleMouseUp(const Point& mousePos, int button) { return false; }
    
    void SetBounds(const Rect& bounds) { m_bounds = bounds; }
    Rect GetBounds() const { return m_bounds; }
    void SetVisible(bool visible) { m_visible = visible; }
    void SetEnabled(bool enabled) { m_enabled = enabled; }
};

示例：创建 Image 控件（显示图片）

class Image : public UIComponent {
public:
    Image() : m_opacity(1.0f) {}
    
    void SetImage(ID2D1Bitmap* bitmap) { m_bitmap = bitmap; }
    void SetOpacity(float opacity) { m_opacity = opacity; }
    
    void Draw(Renderer* renderer) override {
        if (!m_visible || !m_bitmap) return;
        
        // 获取 D2D 渲染目标
        auto* rt = renderer->GetRenderTarget();
        if (rt) {
            D2D1_RECT_F destRect = m_bounds.ToD2D();
            rt->DrawBitmap(m_bitmap, destRect, m_opacity);
        }
    }
    
private:
    ID2D1Bitmap* m_bitmap = nullptr;
    float m_opacity;
};

添加支持圆角的 Image 控件

class RoundedImage : public UIComponent {
public:
    void SetImage(ID2D1Bitmap* bitmap) { m_bitmap = bitmap; }
    void SetCornerRadius(float radius) { m_radius = radius; }
    
    void Draw(Renderer* renderer) override {
        if (!m_visible || !m_bitmap) return;
        
        // 创建圆角矩形裁剪层
        RoundedRect clipRect;
        clipRect.rect = m_bounds;
        clipRect.radiusX = m_radius;
        clipRect.radiusY = m_radius;
        
        renderer->PushClip(m_bounds);  // 或者使用圆角裁剪
        renderer->GetRenderTarget()->DrawBitmap(m_bitmap, m_bounds.ToD2D());
        renderer->PopClip();
    }
    
private:
    ID2D1Bitmap* m_bitmap = nullptr;
    float m_radius = 0;
};

添加速率计 (Gauge) 控件

class Gauge : public UIComponent {
public:
    Gauge() : m_value(0), m_min(0), m_max(100), m_angle(-135), m_targetAngle(-135) {
        m_anim = std::make_unique<Animation>();
        m_anim->OnUpdate([this](float value) {
            m_angle = m_startAngle + value * (m_targetAngle - m_startAngle);
        });
    }
    
    void SetValue(float value) {
        value = std::max(m_min, std::min(m_max, value));
        m_value = value;
        
        m_startAngle = m_angle;
        m_targetAngle = -135 + (value - m_min) / (m_max - m_min) * 270;
        m_anim->Start(0, 1, 0.3f, EasingType::QuadOut);
    }
    
    void Draw(Renderer* renderer) override {
        float cx = (m_bounds.left + m_bounds.right) / 2;
        float cy = (m_bounds.bottom - 20);
        float radius = std::min(m_bounds.Width(), m_bounds.Height() - 40) / 2;
        
        // 绘制背景弧
        DrawArc(renderer, cx, cy, radius, -135, 270, m_trackColor);
        
        // 绘制进度弧
        DrawArc(renderer, cx, cy, radius, -135, (m_angle + 135), m_progressColor);
        
        // 绘制指针
        DrawNeedle(renderer, cx, cy, radius, m_angle);
        
        // 绘制数值文本
        wchar_t buf[32];
        swprintf_s(buf, L"%.0f", m_value);
        renderer->DrawText(buf, Rect(cx - 30, cy - 40, cx + 30, cy), 
                           m_textColor, 24, true, true);
    }
    
private:
    float m_value, m_min, m_max;
    float m_angle, m_startAngle, m_targetAngle;
    std::unique_ptr<Animation> m_anim;
};

事件系统与回调

事件双通道（v2 核心）

同一事件两份副本、两个通道各自消费、互不抢食（qotgui_abi.cpp）：

通道载体消费者
轮询通道g_events 队列qg_poll_event / qg_wait_event（v1 语义，取走即消费）
回调通道g_cb_events 队列drain_events() 在消息泵空闲点派发给 qg_bind 绑定者

回调注册（任意宿主语言，函数指针 + userdata）：

typedef void (*qg_event_fn)(int id, int kind, double value, int x, int y, void *userdata);
int qg_bind(int id, unsigned kinds_mask, qg_event_fn cb, void *userdata);  // 返回 token
int qg_unbind(int token);                                                  // id=0 绑全部来源
线程与安全纪律： 回调在消息循环线程同步执行（延迟一跳：事件先入队、泵空闲点才派发——绝不在控件事件处理栈内同步触发用户代码，否则回调中销毁控件即 use-after-free）。回调内可直接调用任意 qg_* 接口。WM_DESTROY 处理栈内禁止同步析构窗口对象（reap_destroyed_windows 在消息循环外统一析构，防 DestroyWindow 重入）。高频事件（鼠标移动 / 文本改变 / 尺寸改变）只对绑定过的来源入队，防无消费者堆积。

事件 kind 全集（qotgui_abi.h）：1 点击 / 2 改变 / 3 选中 / 8 动画完成 / 9 全关 / 10-15 鼠标 / 16 滚动（v3：value=偏移；滚轮·拖拽·编程滚动统一触发，高频门控） / 20 键按下 / 21 字符 / 22 文本改变 / 30 关闭请求 / 31 尺寸 / 32 焦点 / 33 失焦 / 40 载入 / 50 菜单命令（v3：value=选中项 id，0=取消） / 51 拖放文件（v3：value=文件数，x/y=落点客户坐标；路径经 qg_take_drop_file(i) 在回调内立刻取——批次=最近一次落盘）；绑定掩码 = 对应固定 bit（QG_BIT_*：新 kind 追加高位 0x80000 / 0x100000 / 0x200000，v2 已发布位序不动）。

事件源接线（窗口 → ABI）

// ModernWindow 通过事件汇点把输入/生命周期事件推给 ABI 层
window->SetEventSink([](int kind, int id, double value, int x, int y) {
    push_event(id, kind, value, x, y);   // 高频事件走 push_event_gated
});
// 控件回调（std::function）在创建时固定桥接进队列：
b->OnClick([id]() { push_event(id, QG_EVT_CLICK, 0.0); });

绑定到 QOT 脚本

现行双绑定路径（v2 · 解释器 + 原生同源）

现行 GUI 绑定走 C ABI（qotgui_abi.h/cpp 的 qg_*）+ 两条宿主适配层，与旧 VM 的 gui_module.cpp（已冻结）无关：

宿主适配层机制
解释器（Oracle）primitives.pyctypes 装载 build/qotgui.dll；回调经 CFUNCTYPE + cookie → QotClosure（Evaluator._call_closure）
原生程序（Native）qotrt_gui.cpplir_cgen.py 按 vg_ 前缀自动注入原型；qot_cache.py 链接 wingui 目标；闭包经 qotrt_clo_call 反向调用

加新 vg_* 的四处登记（缺一不可，清单机械校验）：

1. ot-asset/c/wingui/qotgui_abi.h     —— qg_* 声明
2. ot-asset/c/wingui/qotgui_abi.cpp   —— qg_* 实现
3. ot-asset/c/wingui/qotrt_gui.cpp    —— V16 包装（qotrt_vg_*；vg_ 前缀自动注入，无需改 lir_cgen）
4. primitives.py + builtins.toml      —— interp handler（__name__ 与清单逐字一致）+ [[builtin]] 登记
回调桥接： 两侧各自的 trampoline 把宿主函数值存入 cookie 表，事件触发时反向调用——解释器侧 ev._call_closure(clo, [id, value, x, y])，原生侧 qotrt_clo_call。回调异常就地捕获不穿透 C 消息循环（两侧口径一致）。QOT 回调统一签名 fn(id, value, x, y)；QOT 里函数值用 lambda 单表达式委托命名函数。

Value builtin_vg_create_datepicker(const std::vector<Value>& args) {
    auto* window = GUIManager::instance().getMainWindow();
    if (!window) return Value(nullptr);
    
    float x = args.size() > 0 ? gui_valueToFloat(args[0]) : 50;
    float y = args.size() > 1 ? gui_valueToFloat(args[1]) : 50;
    float w = args.size() > 2 ? gui_valueToFloat(args[2]) : 200;
    float h = args.size() > 3 ? gui_valueToFloat(args[3]) : 30;
    
    auto datepicker = std::make_unique<gui::DatePicker>();
    datepicker->SetBounds(gui::Rect(x, y, x + w, y + h));
    
    gui::DatePicker* ptr = datepicker.get();
    window->AddComponent(std::move(datepicker));
    
    return Value(GUIManager::instance().storeObject(
        GUIObject::Type::DatePicker, ptr));
}

Value builtin_vg_datepicker_get_value(const std::vector<Value>& args) {
    if (args.empty()) return Value(nullptr);
    
    std::string objId = args[0].toString();
    auto* picker = static_cast<gui::DatePicker*>(
        GUIManager::instance().getPtr(objId));
    
    if (!picker) return Value(nullptr);
    
    Value result = Value::createArray();
    result.asArray().push_back(Value(static_cast<double>(picker->GetYear())));
    result.asArray().push_back(Value(static_cast<double>(picker->GetMonth())));
    result.asArray().push_back(Value(static_cast<double>(picker->GetDay())));
    return result;
}

常见问题

Q1: 如何实现控件的动画过渡效果？

A: 在控件中添加 std::unique_ptr<Animation>，在 Update 中更新，在 Draw 中使用当前动画值。参考 Button 的悬停动画实现。

Q2: 如何支持高 DPI 缩放？

A: 在窗口初始化时调用 SetProcessDPIAware()，并使用 GetDpiForWindow 获取 DPI，按比例缩放控件尺寸。

Q3: 如何处理 WM_PAINT 时的闪烁？

A: v2 默认路径已是 DirectComposition 合成呈现（DWM 直接合成，无重定向表面参与，天然无闪烁），并保留 WM_ERASEBKGND 返回 1。回退到 HwndRT 时双缓冲同样生效。若需强制回退诊断，设环境变量 QOT_GUI_NO_DCOMP=1。

Q4: 如何添加右键菜单？

A: 在 HandleMouseDown 中检测右键按钮（button == 1），创建 TrackPopupMenu。

Q5: 控件太多导致渲染性能下降？

A: 使用 Renderer 的 PushClip/PopClip 裁剪不可见区域，避免无效绘制。

Q6: TextBox 如何支持多行？

A: 修改 TextBox::Draw 使用 DrawText 的自动换行模式（设置 DWRITE_WORD_WRAPPING_WRAP），并添加滚动支持。

  • 控件扩展 - 继承 UIComponent 创建任意自定义控件
  • 布局扩展 - 实现自定义布局算法
  • 主题扩展 - 定义配色方案、全局样式
