QOT 语言手册

标准库

标准库就是 .qot 源码——没有隐藏实现，可以直接打开读、直接改、直接抄进自己的项目。 仓库里的 std/ 目录是它的全部内容。

1. 引入方式

require "std/fs.qot";
require "std/text.qot";

引入后模块里的函数就进入当前程序的名字空间，可以直接调用，也可以用 模块名##函数名 的写法显式限定：

require "std/text.qot";

var rows = csv_parse(text);         // 直接调用
var rows2 = text##csv_parse(text);  // 显式限定（模块名 = 文件名去掉扩展名）

命名空间纪律

  • 模块是平坦命名空间：引入后模块内的顶层名直接进入主程序名字空间。
  • 主程序若定义同名顶层名，编译期显式失败（不静默遮蔽）。
  • 模块内部私有名一律带模块前缀（_sfs_ / _stx_ / _sdt_ / _scl_ / _net_），避免与主程序撞名。

失败约定

标准库统一：容器类失败返回 null，布尔类失败返回 false， 字符串类失败返回空串 ""。失败不抛异常，调用方需要自己判空。

2. std/fs —— 文件系统

函数 说明
read_lines(path) 按行读文本文件：\r\n 与 \n 统一为无行尾；文件末尾换行视为终止符，不产生空行。失败（打不开 / 路径是目录）→ null
write_lines(path, lines) 按行写文本文件（每行补 \n，覆盖语义）。lines 非数组 → false
append_lines(path, lines) 按行追加（每行补 \n）。失败 → false
walk(dir) 递归遍历目录：返回相对 dir 的路径数组，目录条目带 / 尾；顺序按目录字典序、递归先序。非目录 → null
glob(dir, pattern) 目录内通配匹配：* 任意串、? 单字符；只匹配本层名字，不递归。pattern 为空或取不到名字 → null 
require "std/fs.qot";

var lines = read_lines("data.txt");
if (lines != null) {
    for (ln in lines) {
        output(ln);
    }
}

3. std/text —— 文本与 CSV

函数 说明
csv_parse(text) CSV 解析（RFC 4180）：引号字段、"" 转义、CRLF/LF 行尾、末尾换行不产生空行。返回二维数组
csv_write(rows) 生成 CSV（规范形：字段按需加引号，行尾 CRLF）。输入非数组或行元素非数组 → ""
csv_column(rows, idx) 取第 idx 列；缺失字段得 null，rows 非数组 → null
trim_all(rows) 所有字段去首尾空白；行元素非数组则原样保留
normalize(s) 空白归一：去首尾空白 + 内部连续空白压成单个空格
wrap(s, width) 贪心按词折行；width < 1 → ""；超长单词独立成行，不截断 
require "std/text.qot";

var rows = csv_parse("a,b\n1,2\n3,4\n");
output(csv_column(rows, 1));        // ["2", "4"]

4. std/data —— 统计与分组

函数 说明
mean(nums) 算术平均（Σ/n）。输入必须是纯数字数组（布尔不算数字），否则 null
median(nums) 中位数：在副本上排序，不改输入；偶数个取中间两数平均
stddev(nums) 总体标准差（除以 n，不是 n-1 的样本口径）
group_count(rows, col) 按第 col 列分组计数 → dict{键: 次数}；rows 非数组 → null
group_sum(rows, col, valcol) 按第 col 列分组、对第 valcol 列求和 → dict{键: 和}；非数值单元格跳过 
require "std/data.qot";
require "std/text.qot";

var rows = csv_parse("city,amount\nbeijing,100\nshanghai,250\nbeijing,50\n");
var by_city = group_sum(rows, 0, 1);
output(by_city["beijing"]);       // 150

5. std/cli —— 命令行解析

函数 说明
parse_flags(argv) 解析命令行参数 → dict{"flags": dict, "args": array}。规则：--name=value → 值恒为字符串；--name → true；-abc 短簇 → 每个字符一个布尔旗标；其余为位置参数（保序）；重复旗标后写覆盖。argv 非数组 → null
usage(lines) 打印用法文本（数组逐行、字符串单行），返回是否打印成功
prompt(text) 打印提示后读一行标准输入；EOF → ""。会阻塞，别放在自动化测试里 
require "std/cli.qot";

var parsed = parse_flags(args_get());
if (dict_has(parsed["flags"], "verbose")) {
    output("verbose mode");
}
for (a in parsed["args"]) {
    output(a);
}

6. std/net —— HTTP 客户端

函数 说明
url_parse(url) 解析 URL → dict（协议、主机、端口、路径、查询等）
http_get(url) GET 请求 → dict（状态码、响应头、响应体）；失败 → null
http_post(url, body, ctype) POST 请求；ctype 缺省为表单编码
download(url, path) 下载到本地文件；失败 → null 
require "std/net.qot";

var resp = http_get("https://example.com/api");
if (resp != null) {
    output(resp["status"]);
}

7. 自己写模块

模块就是一个 .qot 文件。把它放进项目目录并 require 即可：

// mylib.qot
any_t func clamp(v, lo, hi) {
    if (v < lo) { return lo; }
    if (v > hi) { return hi; }
    return v;
}
require "mylib.qot";
output(clamp(12, 0, 10));      // 10

约定：模块内的私有函数带前缀（如 _mylib_），避免与主程序撞名。

8. 内置函数与标准库的关系

内置函数是机制层（file_open、str_find、socket_* 等）， 标准库是任务层（按行读文件、解析 CSV、统计分组）。标准库全部由内置原语拼装而成， 因此它们的行为在解释器与原生可执行文件两侧完全一致。完整内置函数清单见 内置函数参考。
