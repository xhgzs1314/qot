类与对象

QOT 的对象模型是最小但完整的：类、字段、方法、构造器。没有继承、没有类层级、没有接口声明—— 多态与接口由「协议元语 + 组合」在库层解决，见 协议元语。

1. 声明一个类

类只能声明在顶层（函数体内不允许声明类）。字段按声明序固定布局，可以带默认值，也可以不带（默认 null）。

class Point {
    var x = 0;                     // 字段（声明序 = 布局偏移）
    var y = 0;
    var label = "";                // 字段默认值可以是任意字面量

    func init(ax, ay) {            // init = 构造器（可选）
        this->x = ax;
        this->y = ay;
    }

    number_t func dist2() {        // 方法（返回类型可省略 = 隐式 any_t）
        return this->x * this->x + this->y * this->y;
    }
}

2. 构造、读字段、写字段

var p = Point(3, 4);      // 构造：字段默认值 → init 体 → 恒返回实例
output(p->x);               // 3        字段读
p->x = 5;                   // 字段写
p->y += 10;                 // 复合赋值同样支持
output(p->dist2());         // 25       方法调用（类型表分派）
output(p->label);           // ""       未赋值的字段 = 声明时的默认值

构造顺序

  1. 按声明序写入字段默认值；
  2. 执行 init 体（this 已绑定到实例）；
  3. 恒返回实例——init 里不能 return（编译期致命）。

没有 init 也可以构造：Point() 只会写字段默认值。

3. this

this 在方法体内恒指接收者，并遮蔽外层同名变量。它可以在方法内的 lambda / 嵌套函数里捕获（走闭包机制）。

class Counter {
    var n = 0;
    func init() { this->n = 0; }
    func bump() { this->n += 1; return this->n; }
    func make_stepper() {
        var self = this;
        return func() -> self->n;      // 捕获 this
    }
}

4. 定价细则

场景 行为
读未声明字段 null（不报错）
写未声明字段 被忽略（不报错）
调用对象上不存在的方法 null（不报错）
非对象接收者 x->m(a) 退化为「receiver 前置」的普通调用：等价于 m(x, a)
两个对象比较（==） 引用同一性——同一个实例才相等
gtypes(obj) / type(obj) "object"
str(obj) "<类名>"（确定性输出，不含地址）
方法返回值 可以继续链式调用：c->inc()->inc()->value()
为什么对象不是字典？字段按声明序固定布局，访问是「类型表偏移查表 + 直接下标」， 与数组下标同族（热循环内每字段读约 7ns 量级）。需要动态属性请用字典。

5. 与协议配合：让对象参与运算与迭代

类本身只提供「字段 + 方法」。想让对象支持 +、==、下标、for-in、字符串化， 写对应的协议方法即可——编译器会在类型可知时直接绑定它们。

class Vec2 {
    var x = 0;  var y = 0;
    func init(ax, ay) { this->x = ax; this->y = ay; }
    func __add__(o) { return Vec2(this->x + o->x, this->y + o->y); }
    func __eq__(o)  { return this->x == o->x && this->y == o->y ? 1 : 0; }
    func __to_str() { return "(" + int_to_str(this->x) + "," + int_to_str(this->y) + ")"; }
}

var s = Vec2(1, 2) + Vec2(10, 20);
output(s);                 // (11,22)
output(s == Vec2(11, 22));  // 1

协议方法的完整清单与绑定规则见 协议元语。

6. 组合代替继承

QOT 没有继承与类层级。需要「is-a」之外的行为组合时，用字段持有另一个对象即可——这也是协议化多态的常见落地方式。

class Engine {
    var kind = "";
    func init(k) { this->kind = k; }
    func sound() { return this->kind + "-hum"; }
}

class Robot {
    var name = "";
    var engine = null;              // 组合
    func init(n) {
        this->name = n;
        this->engine = Engine("ion");
    }
    func speak() { return this->name + ": " + this->engine->sound(); }
}

output(Robot("R7")->speak());      // R7: ion-hum

7. 类的声明顺序

类必须先声明、后使用：Robot 的 init 里用到的 Engine 要在它之前声明。 方法体内的调用可以引用后声明的类，但构造点不行。

不要用 __ 开头的名字。双下划线前缀是编译器内部保留的（隐藏临时变量、 协议绑定脱糖产物、方法接收者改写）。用户自己声明的全局变量若用了这个前缀，在函数体内读取会被编译成局部槽， 读到的将是 null。库代码约定用单下划线前缀（如 _m_emit）。
