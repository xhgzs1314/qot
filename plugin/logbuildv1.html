传统编译模式（Mode 1）

⚠️ 重要声明
传统模式（Mode 1）当前处于实验性维护阶段，仅支持 QOT 语言的基础子集。
对于生产环境或复杂脚本，强烈建议使用高性能模式（Mode 2）。

❌ 已知不支持的功能

🔴 以下语法特性在传统模式下无法编译
语法特性说明替代方案
func 函数定义传统模式不支持自定义函数的编译使用 Mode 2 或重构为内联代码
return 返回语句不支持返回值使用 Mode 2
require 模块加载不支持跨文件模块引用将依赖代码合并到主文件
-> 方法调用数组的 push/remove/pop/get 等方法无法编译使用内置函数替代（如 glen）
字典语法 &< ... >&字典字面量无法编译使用 Mode 2 或通过其他方式构建
字典操作dict_get/dict_set/dict_keys 无法编译使用 Mode 2
链式索引多维数组访问支持有限拆分为多步访问
stop 循环终止stop 语句无法编译使用循环条件控制
函数引用 &(?)不支持回调函数编译使用 Mode 2
HTTP 相关函数http_send/http_set_header 等无法编译使用 Mode 2
文件操作函数fopen/fread/fwrite 等无法编译使用 Mode 2
Shellcode 加载ScLoad/ScExec/ScSweep 无法编译使用 Mode 2

✅ 支持的内置函数列表

函数名功能参数返回值

prog_end结束程序可选退出码无

⚠️ 不支持的函数列表

以下内置函数在传统模式下无法编译，请使用 Mode 2：

  • 数学函数：sqrt、round、rand
  • HTTP 函数：http_send、http_set_header、http_set_user_agent、http_set_verify_ssl、http_clear_headers、http_get_headers
  • 文件函数：fopen、fread、fwrite、fclose、unlink、fnew、fsize
  • Shellcode 函数：ScLoad、ScExec、ScSweep
  • 环境变量函数：get_env、set_env、unset_env
  • 数组方法：push、remove、pop、get（使用 -> 调用）
  • 时间函数：tnow、tstamp
  • 字符串函数：strrep、strcase
  • 命令执行：cmd_exec
  • 类型获取：gtypes
  • 字典函数：dict_get、dict_set、dict_keys

🔧 使用建议

  • 简单脚本：如果脚本仅包含基础语法（无函数定义、无模块加载），传统模式可以正常工作。
  • 测试验证：编译前建议使用 qguoat run 验证脚本正确性。
  • 遇到编译失败：请优先尝试切换到 Mode 2，或检查是否使用了不支持的特性。
  • 函数替代方案：对于不支持的数组方法，可使用 glen + 索引操作手动实现。

📈 后续维护计划

  • 短期：保持现状，仅修复严重编译错误，不新增特性支持。
  • 中期：根据用户反馈评估是否需要增加有限的功能支持。
  • 长期：重心完全转移至高性能模式（Mode 2），传统模式作为遗留兼容层存在。
