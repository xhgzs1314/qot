概述

QOT 虚拟机是一个基于栈的字节码解释器，用 C++17 实现，支持 Windows x86/x64 平台。VM 的核心特性包括：

  • 完整的字节码指令集（30+ 指令）
  • 内置函数系统（文件 I/O、网络、GUI、Shellcode 等）
  • 动态模块加载（DLL 插件，支持 exports.func 和 PluginGetFunction 双接口）
  • RPN 优化器（将纯数值循环编译为逆波兰表达式，大幅提升性能）
  • GUI 绑定（基于 ExDUIR 的现代化 Windows GUI）
  • HTTP 客户端（基于 WinHTTP）
  • Shellcode 加载与执行
扩展目标： 你可以为 VM 添加新的指令、注册新的内置函数、开发 DLL 插件、扩展 GUI 控件，甚至自定义 RPN 优化规则。

步骤3：实现处理函数：

void VMExecutor::opMyNewOp(const std::vector& argData) {
    // 解析参数
    int32_t param = VMLoader::parseArgInt(argData);
    
    if (m_debug) debugPrint("MY_NEW_OP: param=" + std::to_string(param));
    
    // 执行自定义逻辑
    Value result = ...;
    m_currentFrame->stack.push_back(result);
}

void VMExecutor::opMyArrayFilter(const std::vector& argData) {
    // 从栈顶获取数组和回调函数
    if (m_currentFrame->stack.size() < 2) return;
    
    Value callback = m_currentFrame->stack.back(); m_currentFrame->stack.pop_back();
    Value arr = m_currentFrame->stack.back(); m_currentFrame->stack.pop_back();
    
    if (!arr.isArray() || !callback.isFunction()) {
        m_currentFrame->stack.push_back(Value(nullptr));
        return;
    }
    
    std::vector filtered;
    for (const auto& item : arr.asArray()) {
        Value result = callback.asFunction()({item});
        if (result.isTruthy()) {
            filtered.push_back(item);
        }
    }
    
    m_currentFrame->stack.push_back(Value(filtered));
}
提示： 新增指令后需要同步修改 Python 端的字节码编译器（bytecode.py 中的 Compiler._compile_node 和 VMInstruction 类）。

3.2 参数处理最佳实践

static Value builtin_file_read_lines(const std::vector<Value>& args) {
    // 1. 参数数量检查
    if (args.empty()) {
        std::cerr << "[Error] file_read_lines() 需要至少1个参数：文件路径" << std::endl;
        return Value::createArray();
    }
    
    // 2. 参数类型检查
    if (!args[0].isString()) {
        std::cerr << "[Error] file_read_lines() 第一个参数必须是字符串" << std::endl;
        return Value::createArray();
    }
    
    // 3. 可选参数处理
    bool skipEmpty = false;
    if (args.size() >= 2 && args[1].isBool()) {
        skipEmpty = args[1].asBool();
    }
    
    // 4. 核心逻辑
    std::string path = args[0].asString();
    std::ifstream file(path);
    if (!file.is_open()) {
        return Value::createArray();
    }
    
    std::vector<Value> lines;
    std::string line;
    while (std::getline(file, line)) {
        if (skipEmpty && line.empty()) continue;
        lines.emplace_back(line);
    }
    
    return Value(lines);
}

🔌 模块加载器扩展 (DLL/Plugin)

4.1 创建 DLL 插件（高性能接口）

使用 platform_export.h 中定义的宏：

#include "platform_export.h"

// 实现插件函数
PluginValue my_add(const PluginValue* args, int arg_count) {
    if (arg_count < 2) return PluginValue(0.0);
    double a = args[0].num_val;
    double b = args[1].num_val;
    return PluginValue(a + b);
}

PluginValue my_echo(const PluginValue* args, int arg_count) {
    if (arg_count < 1) return PluginValue("");
    return PluginValue(args[0].str_val);
}

// 导出声明

    .add("my_add", my_add)
    .add("my_echo", my_echo)
PLUGIN_END

RPN 优化器扩展

RPN（逆波兰表达式）优化器将纯数值循环编译为高效的计算指令，支持 x86/x64 汇编加速。

5.1 RPN 工作流程

1. 编译器识别纯数值循环 → 插入 RPN_LOOP_START / RPN_LOOP_END 指令
2. VM 执行到 RPN_LOOP_END 时：
   a. 提取循环体字节码
   b. 调用 compile_rpn_loop() 编译为 RPN 指令
   c. 估计循环次数
   d. 快速执行 RPN 指令
3. 完成后跳转到循环出口

5.2 添加新的 RPN 操作

在 rpn_executor.h 中定义新操作码：

// 在 rpn_executor.h 的 RPNInstruction 中，op 字段值：
// 1 - CONSTANT, 2 - VARIABLE, 10 - ADD, 11 - SUB, 12 - MUL, 13 - DIV, 14 - NEG
// 可以扩展：
#define RPN_OP_POW      15
#define RPN_OP_MOD      16

在 rpn_executor.cpp 的 rpn_execute_cpp 中添加处理：

case 15: // POW
    sp--;
    sp[-1] = std::pow(sp[-1], sp[0]);
    break;
case 16: // MOD
    sp--;
    sp[-1] = std::fmod(sp[-1], sp[0]);
    break;

对于 x64 汇编版本（rpn_executor_x64.asm），同步添加：

; 添加新的操作码分支
cmp al, 15
je op_pow
cmp al, 16
je op_mod

op_pow:
    ; 调用 pow 函数（注意浮点栈）
    sub r14, 16
    movsd xmm0, qword ptr [r14]
    movsd xmm1, qword ptr [r14 + 8]
    call pow
    movsd qword ptr [r14], xmm0
    add r14, 8
    jmp loop_start
性能提示： RPN 优化器对数值密集型循环（如矩阵运算、蒙特卡洛模拟）有 5-10 倍性能提升。确保循环内没有函数调用、数组访问等副作用。

Value 类型系统

vm_types.h 中的 Value 类是 VM 的核心数据容器，支持类型：

  • NONE - 未初始化
  • NULL_ - null 值
  • BOOL - 布尔
  • NUMBER - 双精度浮点数
  • STRING - UTF-8 字符串
  • ARRAY - 动态数组（std::vector<Value>）
  • DICT - 字典（std::unordered_map<std::string, Value>）
  • FUNCTION - 脚本函数（std::function<Value(const std::vector<Value>&)>）
  • BUILTIN - 内置函数（同 FUNCTION）
  • CODEBLOCK - 字节码块

常见问题

Q1: 如何调试 VM 执行过程？

A: 调用 vm_set_debug(handle, 1) 或在 C++ 中 executor.setDebug(true)。VM 会打印每条指令的执行信息、栈状态和变量值。

Q2: 添加新指令后如何生成字节码？

A: 需要同时修改 Python 端的 bytecode.py：

# 在 VMInstruction 类中添加新指令常量
MY_NEW_OP = 71

# 在 Compiler._compile_node 中添加编译逻辑
elif node_type == 'my_new_op':
    code.instructions.append((VMInstruction.MY_NEW_OP, argData))

Q3: DLL 插件签名验证失败？

A: 确保 exports.func 已通过签名工具签名。签名使用 HMAC-SHA256 + 自定义 XOR 编码，密钥为 "yhsndnggc_ab_qguoat"。

Q4: 32位和64位 DLL 可以混用吗？

A: 不可以。VM 进程的位数必须与 DLL 的位数匹配。使用 buildx86.bat 编译 32 位版本，buildx64.bat 编译 64 位版本。

Q5: 如何扩展 RPN 支持浮点向量运算（SIMD）？

A: 在 rpn_executor_x64.asm 中使用 AVX 指令集处理批量数据。建议创建专门的 MAKE_VECTOR 和 VECTOR_OP 指令，在汇编层实现 SIMD 加速。

Q6: VM 支持协程吗？

A: 当前版本不支持。可以通过 CALL/RETURN 机制模拟，但需要自己管理调用栈。

Q7: 如何将 C++ 类对象绑定到 QOT 脚本？

A: 使用 Value 的 ptr 类型存储对象指针，在回调函数中进行类型转换。或者封装为内置函数集合，通过句柄（intptr_t）操作对象。

总结

QOT VM 提供了完整的扩展能力：

  • 指令集 - 添加自定义 OpCode 和处理函数
  • 内置函数 - 注册 C++ 函数供脚本调用
  • DLL 插件 - 使用 PLUGIN_BEGIN/PLUGIN_END 宏导出函数
  • RPN 优化 - 扩展逆波兰表达式操作，实现 SIMD 加速
  • GUI 控件 - 继承 UIComponent 类添加新控件
  • Value 类型 - 扩展自定义数据类型
